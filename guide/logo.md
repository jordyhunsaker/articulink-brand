# Logo

The Articulink logo is the lowercase wordmark **articulink** set in Nunito
ExtraBold. The asset files ship in `@articulink/brand` under `assets/` as
SVGs with the type converted to outlines — they render identically
everywhere (emails, `<img>` tags, PDFs) with no font loading and no
third-party requests.

## Files

| File | Color | Use on |
|---|---|---|
| `assets/logo.svg` | Tide `#037DE4` | Light backgrounds (Cloud, Breeze) — the default |
| `assets/logo-white.svg` | Cloud `#FFFFFF` | Tide, Abyss, photos, dark backgrounds |
| `assets/logo-abyss.svg` | Abyss `#012A4D` | Contexts where Tide doesn't work (e.g. print in one dark color) |
| `assets/favicon.svg` | White "a" on Tide rounded square | Favicons, app icons, avatars |

## Clear space

Keep clear space equal to the **x-height of the letters** on all four sides
of the wordmark. Nothing — text, graphics, page edges — enters that zone.

## Minimum size

- **Screen:** 120px wide
- **Print:** 1 inch (25mm) wide

## Don'ts

- Don't stretch or distort
- Don't change the colors
- Don't add shadows or effects
- Don't rotate or skew
- Don't place on low-contrast backgrounds (e.g. white logo on Surf)
- Don't place on busy or multi-color gradient backgrounds
- Don't re-typeset the wordmark — always use the asset files
