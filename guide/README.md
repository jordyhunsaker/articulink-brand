# Articulink written brand guidelines

The canonical written guidelines. Everything here is expressed in code by
this repository's [`@articulink/brand`](../README.md) package — install
that in your project rather than copy-pasting values from these pages. The
interactive version of this guide is the [`site/`](../site/) app at
[design.articulink.com](https://design.articulink.com).
